# Reverse Each Word in a Sentence

## Problem Statement

Given a sentence, reverse the characters of each individual word while keeping the order of the words unchanged.

### Example 1

**Input:**

```text
"Hello World"
```

**Output:**

```text
"olleH dlroW"
```

### Example 2

**Input:**

```text
"Java is Easy"
```

**Output:**

```text
"avaJ si ysaE"
```

### Example 3

**Input:**

```text
"I love coding"
```

**Output:**

```text
"I evol gnidoc"
```
