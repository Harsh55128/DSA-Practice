# Reverse a String

**Difficulty:** Basic  
**Topic:** Strings  
**Points:** 1

## Problem Statement

Given a string `s`, reverse the string and return the reversed string.

## Examples

### Example 1

**Input:**
```text
s = "Geeks"
```

**Output:**
```text
"skeeG"
```

### Example 2

**Input:**
```text
s = "for"
```

**Output:**
```text
"rof"
```

### Example 3

**Input:**
```text
s = "a"
```

**Output:**
```text
"a"
```

## Constraints

- `1 <= s.length() <= 10^6`
- `s` consists only of English alphabets.

## Task

Write a program to reverse the given string.

## Expected Approach

Try solving this problem using a character array or the two-pointer technique.

**Challenge:** Can you reverse the string without using any built-in reverse function?
