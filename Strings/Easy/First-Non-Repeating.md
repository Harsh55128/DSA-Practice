# First Non-Repeating Character

## Problem Statement

Given a string, find the **first character that appears only once** in the string.

If there is no non-repeating character, return `-1`.

### Example 1

**Input:**

```text
"leetcode"
```

**Output:**

```text
"l"
```

### Example 2

**Input:**

```text
"loveleetcode"
```

**Output:**

```text
"v"
```

### Example 3

**Input:**

```text
"aabbcc"
```

**Output:**

```text
-1
```

### Example 4

**Input:**

```text
"swiss"
```

**Output:**

```text
"w"
```
