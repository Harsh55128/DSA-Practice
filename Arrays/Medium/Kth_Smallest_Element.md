# Kth Smallest Element

## Problem Statement

You are given an integer array `arr[]` and an integer `k`. Find and return the **kth smallest element** in the given array.

## Examples

### Example 1

**Input:**

```text
arr[] = [10, 5, 4, 3, 48, 6, 2, 33, 53, 10], k = 4
```

**Output:**

```text
5
```

**Explanation:**

The 4th smallest element in the given array is `5`.

---

### Example 2

**Input:**

```text
arr[] = [7, 10, 4, 3, 20, 15], k = 3
```

**Output:**

```text
7
```

**Explanation:**

The 3rd smallest element in the given array is `7`.

## Constraints

* `1 <= arr.length <= 10^5`
* `1 <= arr[i] <= 10^5`
* `1 <= k <= arr.length`
