# Q1. Reverse an Array

## Problem Statement

Given an integer array, reverse the array in-place.

### Example 1

Input:
[1, 2, 3, 4, 5]

Output:
[5, 4, 3, 2, 1]

### Example 2

Input:
[10, 20, 30]

Output:
[30, 20, 10]

## Constraints

- 1 <= n <= 10^5
- -10^9 <= arr[i] <= 10^9

## Expected Approach

Try to solve this problem using the **two-pointer approach**.

## Task

Write a Java program to solve the problem.
